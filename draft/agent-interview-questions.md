# Agent 开发面试题清单（通用版）

> 定位：一份可复用于任意 Agent 实现/源码的面试与学习关注点清单，面试官口吻，通用、精准、不绑定具体实现。

## 来源与演进

- **起点**：初步整理的 8 个宽泛主题（Loop / 上下文 / 压缩 / 持久化 / Tool / Goal / Memory / Multi-Agent）。
- **演进轨迹**：
  1. 转成面试官提问口吻（口语化、开场大问题 + 追问）。
  2. 扩展为 10 个主题：补充「规划范式」「评估与可观测性」「安全与鲁棒性」「成本与性能」，并把「Goal/长期任务」拆分并入「规划」和「持久化」消除重复。
  3. 探索 `../related-repos/` 下两个 Agent 实现（pi 完整 harness、claude-code 源码快照），用真实设计决策反向提炼"该问多深"的考点。
  4. 通用化：剥掉源码特有名词（函数名、表名、字段名、内部机制代号），只保留通用考点与业界通用术语。

- **关键判断**：源码探索的价值在于提炼"追问深度与易漏角度"（停止判据、截断恢复、崩溃恢复的副作用安全、记忆存储选型、子 agent 隔离等），而非把实现细节写进题目。因此正文不出现任何具体实现的专有名词。
- **保留说明**：规划范式、向量检索记忆、多 agent 的 debate/supervisor 等机制，两个参考仓库未实现或未完整实现，但属业界必考，照常保留。

# 正文

## 1. 规划与推理范式（Planning & Reasoning）

> "Agent 的推理范式你了解哪些？ReAct、Plan-and-Execute、Reflection / Reflexion、Tree-of-Thoughts？"

- ReAct 为什么是基线？Plan-and-Execute 什么时候比逐轮 ReAct 更稳？
- Reflection / Reflexion 是让模型自己评估产出再修正，和普通"重试"的本质区别在哪？
- 长期任务怎么拆子目标？plan 怎么维护、执行中怎么更新？
- 怎么防目标漂移（goal drift）？模型跑偏了你靠什么把它拉回来？
- 输出被 token 上限截断后，怎么引导模型"接着干"而不是从头重来？这算不算一种弱的自我修正（self-correction）？

## 2. Agent Loop / 执行引擎

> "核心执行循环怎么设计？"

- 一个 loop 里干了哪几件事——调模型、收集工具调用、执行工具、回填结果、进下一轮？这个状态机怎么建模？
- **停止判据**：模型返回的"停止信号"可信吗？你怎么判断这轮该继续还是该结束——是直接信任模型的标记，还是自己另做判断？为什么？
- 终止条件有几类：模型自己停 / 步数上限 / token 预算 / 成本预算 / 用户中断 / 工具主动终止？各自在哪一层拦？
- 输出被 token 上限截断、末尾还带着残缺的工具调用，怎么恢复？是整批作废重发，还是升级配额续写？
- 主模型失败切备用模型重试，怎么处理中途残留的半成品状态？
- 流式输出怎么和 loop 结合？结构化输出不合规怎么办？
- 重试策略：什么错可重试、什么不可？退避、上限、幂等怎么保证？

## 3. 上下文工程与压缩

> "上下文怎么拼、涨上去怎么压？"

- 上下文里有哪些信息块？哪些静态写死、哪些动态拼装？
- 系统提示、用户上下文、环境上下文这些怎么组织？哪些该放一起、哪些要拆开？拆分的依据是什么（比如缓存友好、变更频率）？
- 动态获取的信息里，哪些取"会话开始时的快照"、哪些要实时刷新？为什么？
- token 预算怎么分配？工具定义怎么裁剪（只放相关工具）？prompt caching 怎么用、什么时候主动失效？
- 上下文压缩可以分几级（从轻量裁剪到重量级重写）？各在什么场景触发？
- 一份合格的压缩摘要要保留哪些要素（目标、进度、决策、约束、待办、失败历史）？为什么是这些？
- 多轮压缩后怎么保证最初的目标和关键决策不丢？
- 压缩在哪个位置切分？哪些消息块不能被拆开？单轮特别长、超了预算怎么办？

## 4. 工具调用（Tool Use）

> "你的 tool 怎么设计？"

- 一个工具定义包含哪些字段？除了名称、描述、参数 schema、执行、返回结构，还需要什么？
- 工具描述是静态字符串，还是能随输入/上下文动态生成？为什么需要动态？
- 怎么声明一个工具是否只读、是否有破坏性副作用、是否需要权限确认？
- 工具返回怎么进上下文：作为消息回填，还是结构化字段？给模型看的和给日志/UI 看的要不要分开？
- 工具结果特别大怎么办：截断、落盘给个引用、还是摘要？
- 工具失败怎么处理：抛异常打断循环，还是作为正常结果交还模型让它自己决定重试/换参/上报？
- 工具集能不能在运行中动态增删？解决了什么、有什么风险？
- 工具调用什么时候能并发、什么时候必须串行？工具列表的排列顺序有没有讲究（比如和缓存相关）？
- 工具协议要不要标准化（比如 MCP）？标准化的收益和边界在哪？

## 5. 记忆系统（Memory）

> "上下文是短期工作记忆，memory 是长期。长期你怎么做？"

- 分层怎么设计——短期 / 长期 / 工作记忆各存什么、生命周期多长？
- 底层存储选型：键值、向量库、图数据库、普通数据库分别适用什么？什么时候简单键值就够、什么时候必须上向量检索？判据是什么？
- 写入时机：任务结束反思、每步写、还是事件触发？重复 / 冲突记忆怎么合并？淘汰按什么原则——重要度、recency + frequency、LRU、TTL、语义去重？
- 检索：怎么在恰当时刻取到恰当内容？"当前这一步要不要查记忆"这个决策怎么做？
- Memory 和 RAG 的区别？（主动积累经验 vs 按需检索知识）

## 6. 状态持久化与恢复（durable execution）

> "Agent 跑到一半崩了、机器重启了，怎么从现场继续？"

- 存什么格式、哪些内容、什么时候写？append-only 日志（event sourcing）和"可覆盖的快照"怎么取舍？
- 恢复是"重放操作日志"，还是"读一个持久化的进度快照"？两者什么 trade-off？
- "工具执行到一半"崩溃了，恢复时怎么知道它到底执行了没、结果落库了没？
- 恢复时工具要不要重跑？怎么判断一个工具重跑是安全的，还是会产生重复副作用？不安全的怎么办？
- 怎么保证同一时间只有一个写者？多进程交替写会出什么问题？
- 恢复时发现持久化状态损坏或不一致，是拒绝启动还是尽力修复？为什么？
- 正常关闭和崩溃，在持久化上能不能统一成一套处理？

## 7. 多智能体编排（Multi-Agent Systems）

> "多 Agent 编排你了解多少？"

- 拓扑有哪几种：中心化（orchestrator / supervisor）、去中心化（peer）、层级（hierarchical）？
- 机制：subagent、supervisor、swarm / handoff、debate、map-reduce、actor-critic——各自原理和适用场景？
- 子 agent 是作为"工具"被主 agent 调用，还是独立运行时？两者取舍？
- 子 agent 和父 agent 的状态、上下文、权限，默认共享还是隔离？哪些该共享、哪些必须隔离？
- 子 agent 的权限怎么和父层协调（比如需要用户确认的操作）？
- 派生子任务时怎么最大化复用父任务的上下文缓存？
- 子任务在成本上怎么单独控制——降级模型、关闭推理、裁剪上下文？
- 通信模型：消息传递 vs 共享黑板？子 agent 结果怎么汇总回主 agent？

## 8. 评估与可观测性（Evaluation & Observability）

> "你怎么评估一个 Agent 做得好不好？怎么观测它运行时在干什么？"

- 评估单元：只评最终答案够吗，还是连中间每一步的轨迹一起评？为什么轨迹重要？
- 用什么评判：确定性脚本、规则 judge、还是 LLM-as-judge？各适用什么？LLM-as-judge 怎么减少偏差？
- 对比两个 Agent 版本，怎么量化好坏（正确率、成本、延迟、轨迹质量）？golden set 怎么维护？
- 可观测性怎么建模：事件、span、trace 怎么组织？高基数和低基数属性为什么要区分？
- 恢复、重试、权限拦截这些关键事件要不要纳入观测？为什么观测和恢复不该是两套割裂的系统？
- 中间步骤怎么观测？每步的可观测信号是什么？

## 9. 安全与鲁棒性（Security & Robustness）

> "Agent 的安全边界你怎么守？"

- prompt injection：用户输入、工具返回内容夹带指令怎么办？
- tool result poisoning：检索 / 工具结果里藏恶意内容怎么防？
- 权限有几个层次：工具级权限声明、运行时审批、沙箱隔离？什么时候用哪个层次？
- 敏感操作的人审（human-in-the-loop）挂在哪？
- 怎么防死循环、防失控（反复调工具烧预算）？预算的兜底在哪层？

## 10. 成本与性能

> "Agent 落地最头疼成本和延迟，你怎么优化？"

- token 和成本怎么记账？要不要区分输入 / 输出 / 缓存命中？为什么？
- 成本状态要不要跨会话持久化、支持恢复后连续统计？
- prompt caching 怎么用：哪些内容适合缓存、怎么让它稳定命中、什么时候主动失效？
- 模型路由：简单任务用小模型、复杂用大模型，怎么决策？运行中能动态切换吗？
- 延迟优化：并行工具、流式输出、减少往返次数？
- 子任务 / 子 agent 的成本怎么单独控制？
