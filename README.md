# AI 结对学习模板

这是一个与 AI 结对学习的工作仓库。它不只保存最终答案，也保留从“为什么不理解”到“如何找到答案”的学习过程。

## 仓库结构

```text
.
├── .agents/          # 可复用的 AI Skill
├── origin-docs/      # 原始资料及其忠实翻译
├── related-repos/    # 以 Git submodule 保存的只读参考仓库
├── draft/            # 从学习对话中提炼出的中间过程
└── output/           # 经过整理的正式文章或学习成果
```

### `.agents`

只存放可复用的 AI Skill。学习笔记、对话草稿和正式文章不放在这里。

### `origin-docs`

保存从外部收集的原始资料，也可以在原文旁保存忠实翻译。原文不在这里润色、摘要或批注。

### `related-repos`

保存用于阅读和分析的相关开源仓库。这些仓库以 Git submodule 形式存在，默认不修改其内容。

### `draft`

保存学习对话的提炼稿：最初的困惑、探索路径、问题链、简短答案、认知变化和未解问题。它是之后写作的参考，不是可直接发布的文章。

### `output`

保存基于原始资料、参考仓库和学习草稿进一步整理得到的正式产出。

## 建议工作流

```text
阅读 origin-docs 或 related-repos
→ 与 AI 提问和探索
→ 调用 $distill-learning-dialogue
→ 在 draft 中检查学习轨迹
→ 后续基于 draft 写入 output
```

`draft` 保存理解形成的过程，`output` 保存经过组织后的正式表达。两者不互相覆盖；产出正式文章后，原始学习草稿仍然保留。
